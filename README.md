# 零号协议 2046 / AGI PROTOCOL 2046

> **开源**：本项目采用 [CC BY-NC 4.0](LICENSE)（署名-非商业性使用）许可。可自由分享、复制、演绎（含代码与美术），但**必须署名、不得商用**。欢迎提 Issue 与 PR（见 [CONTRIBUTING.md](CONTRIBUTING.md)）。

一款 1–4 人本地热座合作的赛博朋克战术 RPG。16 名 AGI 拟人角色、7×5 六边形战场、d100 判定、装备强化与安全屋复活，组成三幕完整冒险：**霓虹港 → 镜海穹顶 → 零号轨道**。

> 基调：七分正经，三分梗。角色原型来自网络上的 AI 人格印象，但故事、技能与关系均为本作原创。

当前版本：`0.25.0`「完整试玩版」——三幕故事、16 名角色、12+4 个规则变异、三个差异化首领、8 条装备特性全部可玩；
玩法已定稿，仍在按真实对局调平衡（见 `HANDOFF.md` §3.9 的验收数字与已知限制）。
（早期版本自称「Demo」，是因为内容还没齐；现在内容齐了，用「试玩版」更准确。）

## 1. 现在能玩到什么

- 标题页、角色选择、1–4 人本地热座创建；每名玩家轮流行动。
- **公网联机**：房主点「创建联机房间」直接开房、拿 **6 位房间码**；再开一条公网隧道（`node tools/tunnel.mjs`），把隧道地址 + 房间码发给朋友，**任何地方的人**用浏览器打开就能加入。**每个人在大厅里自己选角色**（被队友先选走的不给选），都选好后房主开局。轮到自己才有操作权；刷新页面自动重连；房主可以「踢出」捣乱的人，也可以「跳过」卡住的回合。
- **三幕、每幕 95 个节点（17 层 × 5 道 + 起点/首领 + 11 块空地），共 285 个探索节点**。事件只占 9.5%，其余是战斗、服务器、遗骸、陷阱与补给——路很长，每一步都有事。
- 7×5 六边形回合制战斗，最多 4v4；移动、技能、Focus、终极技、敌人 AI、地形与掩体。
- 16 名角色，每名角色 1 个被动、2 个主动技能、1 个终极技；规则库共 **79 个技能定义**（含敌人与召唤技能）。
- **37 件装备**、5 个槽位、5 个稀有度（普通/稀有/史诗/传说/神话）、+0～+5 强化。
- **5 套套装**：霓虹猎手、零号协议、下城拾荒者、镜海议会、轨道圣所；2/3/4 件阶梯加成，背包页显示当前激活进度。
- **22 种敌人**（含 3 名首领与召唤物）、**16 个随机事件**；d100 属性检定、商店购买、背包与装备更换。
- 安全屋休息、装备强化、消耗记忆币与队伍生命复活队友。
- 三名首领：拍卖人、镜面执政官、零号协议·主脑。前两幕首领胜利后进入**幕间整备**，保留等级、装备、套装、记忆币、合金、队伍生命与背包，并进入下一幕。
- **存档与续玩**：服务端把进行中的对局落盘到 `data/sessions/`，刷新页面或重启服务端都能在标题页点「继续行动」接着打；放弃或通关时自动清理。
- **音效与氛围**：全部由 WebAudio 实时合成（点击、骰子、命中、失手、受伤、治疗、拾取、购买、升级、幕间、胜利、失败），外加一层低音量环境垫音；顶栏 ♪ 可静音，设置会记住。
- **战斗演出**：骰子面板、命中/暴击/失手音效、受伤震屏、幕间白光转场、弹窗入场动画；**换人时有一帧角色过场**（头像 + 名字 + AP），联机只在你自己的回合弹。
- **极简叙事**：开场、换幕、拿到密钥、追踪告急时会弹一张文字卡（标题 + 正文 + 继续），读完记入 `seenBeats` 不再重复；不做演出、不配音，全靠文字。
- **小型战斗**：每幕 20 场 1–2 个敌人的遭遇，血量 70%，目标 1–2 回合结束；每场只教一个机制，开战提示写清敌方套路。
- **废弃服务器**：每幕 9 台，位置固定、开局可见。**一台只提升一项数值、只给使用它的那个角色**（VIT/C/H/E/SPD/L 各一台，外加医疗、冷却、日志）；每人每幕最多写入 2 次，第 3 台烧毁接口改为返还 60 记忆币。
- **陷阱与遗骸**：每幕各 8 个。陷阱进入即触发，d100 检定，失败掉 8–14% 最大生命但**永不致死**；遗骸给 20–35 记忆币，60% 附赠道具、8% 附赠装备，并留一句遗言。
- **消耗品**：止血针、聚焦剂、净化剂、护盾发生器、肾上腺素。探索用消耗 1 AP，战斗中用占该单位行动；与装备分开存放，可堆叠。
- **三片密钥**：最终目标拆成 3 片，由 6/12/15 层的三名「碎片看守」把守，必须集齐才能进首领。三片分散在三条不同 lane，强制横向穿图。
- **找回自我（觉醒）**：每幕第 9 层有一个「自我残响」节点（**开局可见**），**全局只允许一名角色觉醒**。觉醒者获得该角色的专属武器（宪章的《合规法典》、鲸落的电饭煲、疾风的法棍……），三个技能全部换成强化版（+1 骰、+1 伤害、冷却 -1）。名额一旦用掉，地图上后续的觉醒节点会置灰标注 `SPENT`——不再诱导绕路，点了也只会提醒你名额已用尽。
- **支线任务**：每幕第 4 层与第 13 层各有一个「残响」节点（开局可见、只在本幕有效）。残响会提出一条可选支线——寻物（去遗骸/宝库找东西）、猎杀（清战斗或击败精英）、探索（走到指定层）、行动（写入服务器）。接受后进度显示在右侧 INTEL 面板，达成后到**任意残响**领取装备、消耗品、追踪或队伍生命；不做也能通关，换幕自动失效且不惩罚。集满 4 条会在结局多一段文字。
- **空白地块**：每幕 11 个虚线「空地」，旁白池扩到 18 条并按层段取用；走进去仍只给一句城市旁白。
- **地图补给**：每幕 5 个商店、5 个安全屋。商店固定上架 2 个消耗品，首访赠送一次全队 15% HP 补给。
- **危险提示**：低等级时精英与碎片看守会显示红色「危险」角标；首领节点标注建议等级，未集齐碎片时直接显示进度。
- **角色标签**：16 名角色全部标注战术定位（爆发 / 持续 / 增益 / 减益 / 护盾 / 治疗 / 召唤 / 控制），选角时一眼能配队。
- **敌方驱散**：天秤的「罪证标记」可以剥夺目标的全部增益与护盾——全角色唯一，留给需要拆盾的场合。
- 桌面与窄屏浏览器布局；游戏图片与逻辑资源本地托管，字体通过 Google Fonts 加载（离线时回退系统字体）。

17 层长图下，自动流程单幕约 5–6 分钟（机器不读文本、不绕路）；按人类节奏估算三幕 **6–7.5 小时**，速通约 **3 小时**。

## 3. 启动

在项目根目录执行：

```powershell
dotnet run --project src/AGI2046.Server/AGI2046.Server.csproj
```

然后打开：

```text
http://localhost:5178
```

首次启动会自动还原并编译。若只想编译：

```powershell
dotnet build src/AGI2046.Server/AGI2046.Server.csproj
```

服务端监听 `0.0.0.0:5178`，同一局域网内的其他设备可以直接用本机 IP 访问；要跨公网就再开一条隧道（见下）。

### 联机怎么开（公网）

1. **房主**：另开一个终端，运行
   ```powershell
   node tools/tunnel.mjs
   ```
   默认走 **Cloudflare Quick Tunnel**（`tools/bin/cloudflared.exe`），输出一个 `https://xxxx.trycloudflare.com` 的公网地址，并写入 `data/tunnel.json`（服务端会自动带出来）。**没有中转警告页**，连上就能玩。
   如果 cloudflared 不可用，可以退回 ssh 隧道：`node tools/tunnel.mjs serveo`。
2. **房主**：标题页点「创建联机房间」直接进大厅（不用先替别人选角色），弹出「选择你的角色」挑一个；大厅显示 6 位房间码和公网地址，点「复制地址 + 房间码」发群里。
3. **朋友**：打开地址 → 「加入房间」输入房间码 → 进大厅后同样弹出「选择你的角色」，从 16 名执行体里挑一个没人选的。
4. 所有人都选好角色后，房主点「开始对局」。

> 隧道地址在**每次重启 `tools/tunnel.mjs` 后都会变**，换完把新地址重新发一下；游戏服务本身不用重启。

> **想让服务一直在线、不用开着自己电脑**：**腾讯云轻量（中国香港，2 核 2G，38–54 元/月）** + Docker Compose + Caddy，
> 本地 `node tools/deploy/deploy.mjs root@<IP> game.你的域名.com` 一条命令打包、上传、启动、验收。
> 存档挂在卷里、证书自动续、轻量控制台的防火墙记得放行 80/443。完整步骤与踩坑见
> [`docs/DEPLOY.md`](docs/DEPLOY.md)（0 元方案、备份、回滚也在里面）。

### 停止与重启

修改 C# 代码后需要停止占用 5178 端口的进程再重新编译；修改 `web/` 下的静态文件只需刷新浏览器。进行中的对局会落在 `data/sessions/`，联机房间落在 `data/rooms/`，重启服务端后自动恢复（最后一次写盘之后的进度可能丢失）。

## 4. 三幕流程

| 幕 | 舞台 | 目标 | 首领 |
| --- | --- | --- | --- |
| 第一幕 | 霓虹港 | 找到王冠密钥，关闭拍卖人的零号协议 | 拍卖人 |
| 第二幕 | 镜海穹顶 | 取得穹顶权限密钥，切断上层协议节点 | 镜面执政官 |
| 第三幕 | 零号轨道 | 取得零号核心密钥，登上协议主脑 | 零号协议·主脑 |

每幕保留相同的 14 节点结构，但节点类型、名称、事件、敌人与掉落由幕数决定。三名首领都拥有独立的护盾、召唤与范围攻击配置。

### 幕间整备

第一幕、第二幕首领胜利后不会立刻结算，而是进入幕间：

- 全队至少恢复至 50% 最大 HP；战斗中倒下的成员以 30% HP 重新上线。
- AP、Focus、技能冷却与终极技使用状态重置。
- 等级、经验、装备、套装、背包、记忆币、合金、队伍生命全部保留。
- 获得下一幕的进入奖励：记忆币、合金与经验。
- 电子追踪计时、密钥、节点清理状态与战斗状态重置。
- 点击幕间面板的「进入下一幕」后，生成下一幕地图并开始探索。

第三幕首领胜利后进入最终结算，显示完整结局。

## 5. 操作说明

### 探索

1. 标题页点击「接入协议」。
2. 选择 1–4 名角色，点击「进入霓虹港」。
3. 点击与当前位置相邻的节点移动；每名角色每轮 3 AP。
4. 到达节点后再次点击当前节点，触发事件、战斗、商店或安全屋。
5. 点击「结束回合」交给下一名角色；热座模式下由同一台设备轮流传给队友。
6. 右上角可以打开「装备 / 背包」和「协助队友」。
7. 走到「残响」（✦）节点再点一次互动：残响会提出一条支线，选「接下这件事」或「走开」。达成后回到任意残响节点领取报酬。

### 联机时

- 只有轮到你时才能点地图、放技能；其他人看到的是「等待 XX 行动…」。
- 战斗里同理，只有当前行动单位的主人能操作。
- 房主额外有一个「跳过这一回合」的按钮，用于队友掉线卡住的时候。
- 刷新页面会自动回到房间/对局（token 存在浏览器里）。

### 战斗

- 点击高亮六边形移动；移动不结束回合。
- 点击技能卡，再点击高亮敌人释放；普通攻击、防御、结束回合在战斗操作栏。
- 技能消耗 Focus；终极技每场战斗只能使用一次。
- 攻击、技能或防御会结束当前单位回合。
- **打不过可以撤**：战斗面板右下角「撤离」→ 全队退回进入战斗前的节点，代价是参战成员 -10% 最大生命；节点不会清空，之后还要再打一次。
- 敌人头顶会显示**下回合意图**（技能、目标、伤害），以及**护甲/抗性/你这下能打多少**（`甲 0 · 抗 9 · 受 2`）。
- 技能卡显示 `2 次 × 3 ≈ 6 伤害 · 命中 75% · 期望 5`：命中率和期望伤害都是明码。
- 幕间三页签：**情报 / 强化 / 换装** —— 打完首领就能花记忆币，不用等下一个安全屋。
- 顶部显示行动顺序、当前单位和回合数。
- 战斗结束后点击结算面板返回节点图；倒下的队友不会自动复活，需要去安全屋，或等待下一幕幕间整备。

### 安全屋

- **休息**：恢复生命，消耗 AP。
- **强化**：消耗记忆币与合金，把装备从 +0 强化到 +5；不会失败，也不会损坏。
- **复活**：消耗 60 记忆币和 1 点队伍生命，让倒下的队友以半血重新上线。

### 检定

事件中的属性检定使用 d100：

```text
目标值 = clamp(DC + 属性修正 + 协助加成 / 2, 5, 95)
掷骰 <= 目标值 即成功
```

界面会显示成功率与实际目标值；掷骰结果会出现在骰子浮层和战斗日志中。

## 6. 核心规则摘要

### 属性与生命

六项属性范围 0–95：

`VIT 体质`、`C 智识`、`H 武技`、`E 共情`、`SPD 速度`、`L 幸运`

```text
MaxHP = BaseHP + Level + floor(10% × Level × VIT)
```

装备、等级和被动会继续修正生命、护甲、抗性、闪避、命中、伤害和移动。

### 战斗

- 7×5 六边形格；普通/精英遭遇随实际参战人数缩放，首领也会按人数调整随从数量与生命。
- 护甲减免物理总伤害，抗性减免技术总伤害；掩体与守护被动会额外提供减伤。
- 敌人 AI 会优先攻击低血量目标；医疗机治疗友军；首领在低血量时使用护盾，并在预算内召唤增援。
- 队伍生命为共享复活资源，当前为 3 点。战斗胜利不会自动消耗队伍生命复活队友；是否在安全屋复活是玩家的取舍。
- 队伍全灭或电子追踪归零时任务失败。

### 装备与套装

- 武器、护甲、头盔、饰品、义体五个槽位。
- 强化只消耗记忆币与合金，不失败、不破碎。
- 套装按已装备件数激活 2/3/4 件效果；不同幕的套装侧重不同：
  - **镜海议会**：闪避、抗性、命中与全属性。
  - **轨道圣所**：护甲、抗性、Focus、命中与全属性。

### 首领

- **拍卖人**：全体技术伤害「记忆拍卖」、护盾「保证金」、增援「雇佣增援」。
- **镜面执政官**：全体技术伤害「镜面回响」、护盾「镜面壁垒」、召唤「复制体」。
- **零号协议·主脑**：三段全体技术伤害「零号脉冲」、护盾「终焉壁垒」、召唤协议碎片、单体高伤「删除请求」。

单人模式会减少首领随从与敌方伤害加成；2–4 人模式逐步提高压力。

### 前后端边界

- `AGI2046.Rules` 不依赖 ASP.NET Core 或浏览器，只处理游戏状态与规则。
- `AGI2046.Server` 只负责会话、HTTP、JSON 和静态文件。
- 浏览器端只持有 `GameState` 快照，通过 `/api/action` 提交动作，不在客户端计算规则结果。
- API 使用 camelCase 属性和 camelCase 枚举字符串。
- 会话目前存放在 `ConcurrentDictionary` 中，适合本地热座与原型验证。

### HTTP API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/health` | 服务健康检查 |
| GET | `/api/meta` | 三幕、角色、技能、装备、套装、敌人、事件、支线与版本信息 |
| POST | `/api/new` | 创建新游戏；请求体 `{ characterIds, seed? }` |
| POST | `/api/action` | 提交动作；请求体 `{ sessionId, action }` |
| GET | `/api/state?sessionId=...` | 读取当前状态 |
| POST | `/api/room/create` | 创建联机房间，返回 4 位房间码与房主 token |
| GET | `/api/room/{code}` | 房间与座位状态（大厅轮询用） |
| POST | `/api/room/{code}/join` | 加入房间（或凭 token 重连），服务端分配座位 |
| POST | `/api/room/{code}/character` | 各自选角色；被队友选走的返回 409 |
| POST | `/api/room/{code}/start` | 只有房主可调用，创建对局并绑定房间 |
| POST | `/api/room/{code}/leave` | 离开房间（大厅阶段房主离开会解散房间） |
| GET | `/api/room/{code}/state?token=&since=` | 联机轮询：返回房间 + 对局；修订号没变返回 `204` |
| GET | `/api/whoami` | 回显服务端看到的来源 IP / Host（隧道排障用） |

浏览器通过 `POST /api/action` 驱动所有状态变化；规则层不依赖 HTTP，因此回放系统或其它宿主可以直接复用同一份逻辑。

## 10. 已知限制

- **联机依赖第三方隧道**：公网地址来自 Cloudflare Quick Tunnel（`trycloudflare.com`，无警告页）或兜底的 serveo ssh 隧道；URL 每次重启都会变，偶尔会断线重连。
- **无账号体系**：加入凭证是 6 位房间码 + 座位 token。房间码已从 4 位升到 6 位（32⁶ ≈ 10 亿），并对建房/查房/认领做了频率限制，但**没有密码**——知道房间码的人就能进。别把地址贴到公开场合。
- **联机战斗掉线**：房主的「跳过」会自动识别阶段——探索时推进轮次，战斗时跳过当前战斗单位。
- 单人模式可以通关，但容错低于 2–4 人合作；推荐首次体验使用 2–4 人。
- 尚未包含背景音乐与配音；音效已有，但听感未经人工确认。
- 规则层暂无单元测试，验证以 HTTP 端到端与 file-based 冒烟脚本为主。
- 游戏内容为原创同人式虚构，不代表任何现实公司或人物的官方设定。
