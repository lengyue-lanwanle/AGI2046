02 · 这一版加的系统

废弃服务器SERVER

六属性各一台（VIT/C/H/E/SPD/L）+ 医疗 / 冷却 / 日志。每台只加一项、只给使用者，每人每幕上限 2 次，第 3 台烧接口返 60 币。

陷阱与遗骸TRAP / CORPSE

陷阱按 SPD/L 做 d100 检定，失败掉血但不致死；遗骸给币、道具、8% 装备，并留一句遗言。

消耗品CONSUMABLE

止血针 / 聚焦剂 / 净化剂 / 护盾发生器 / 肾上腺素。探索耗 1 AP，战斗占一次行动，和装备分开堆叠。

三片密钥KEY SHARDS

终局目标拆给 6/12/15 层三名看守，必须集齐才开门。三片分属三条 lane，强制横向穿图。

敌方驱散DISPEL

新增 dispel：清空目标全部增益与护盾。只挂在天秤「罪证标记」上，全角色唯一。

战术标签TAGS

16 名角色全部标注爆发 / 持续 / 增益 / 减益 / 护盾 / 治疗 / 召唤 / 控制，选角页直接显示。
