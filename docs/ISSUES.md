## 三、联机设计决策（为什么是这样）

### 1. 为什么用 HTTP 轮询而不是 WebSocket

- 项目零依赖（无 npm、无构建），`fetch` + `setInterval` 是最小改动。
- 局域网延迟低，1.5 秒轮询对回合制完全够用。
- 服务端用 `Revision` + `since` 参数实现**条件返回**：状态没变返回 `204 No Content`，几乎不耗带宽。
- 代价：轮到自己时最多有 1.5 秒延迟。要更快可以改成 800ms，或在该玩家回合时切到短间隔。

### 2. 为什么房间在 Server 层而不是 Rules 层

- `AGI2046.Rules` 是纯规则库，将来要给其它宿主直接引用；房间/座位/token 属于传输层概念。
- 对局状态仍然是同一个 `GameState`，房间只负责“谁能操作哪个 PlayerId”。
- 因此**单人热座和联机共用同一套规则与存档**：房间模式只是多了一层鉴权包装。

### 3. 鉴权模型

```
房间码 (6 位)  ──→ 加入房间 ──→ 各自选角色 ──→ token（UUID）
token ──→ seat.PlayerId ──→ 只允许操作这个 PlayerId
```

- 战斗里 `action.PlayerId` 可能为空（前端提交 `combatAction`），所以额外校验**当前 active 单位的 owner**。
- 非行动玩家也能做的动作：`ackBeat`（读剧情卡）、`advanceAct`（幕间进入下一幕）、`acceptQuest`/`declineQuest`。这些都是“确认类”，不改变行动权。
- 房主额外拥有 `forceSkip`。

### 4. 断线重连

- token 存 `localStorage['agi2046.room']`，刷新页面时 `restoreRoom()` 先于热座存档恢复执行。
- 服务端重启后房间从 `data/rooms/{code}.json` 恢复（已验证：lobby 与 playing 都能回来）。
- 在线状态 = `LastSeenUtc` 在 20 秒内；靠轮询刷新，所以**没有心跳包**。

### 5. 公网接入：Cloudflare Quick Tunnel 优先，ssh 隧道兜底

- **主方案**：`tools/bin/cloudflared.exe --url http://localhost:5178`（Quick Tunnel）。无需账号、无需域名、HTTPS、**没有中转警告页**，边缘网络比免费 ssh 隧道稳。
  - 获取方式：github 主站时通时不通，`winget install` 会卡在 release 下载；最后用 `https://gh-proxy.com/https://github.com/cloudflare/cloudflared/releases/download/...` 镜像下载到 `tools/bin/`（已 gitignore）。
- **兜底方案**：`node tools/tunnel.mjs serveo`，ssh 反向隧道，零下载零账号，代价是首访有一次 Serveo 的 “Do not enter sensitive information” 提示页（点 Continue to Site 即可）。
- `tools/tunnel.mjs` 把两种都包了：解析地址、写 `data/tunnel.json`、服务端通过 `/api/health`、`/api/meta` 带出 `publicUrl`。
- 隧道下服务端看到的 `RemoteIp` 全是 `127.0.0.1`，真实来源在 `X-Forwarded-For` / `CF-Connecting-IP`；限速按它区分（`/api/whoami` 可自查）。
- **换更有保障的方案**（固定域名）：Cloudflare 命名隧道 + 自有域名（需账号），或直接部署到云服务器；服务端和前端都不用动。

### 6. 公网暴露后的防护取舍

- 房间码 4 → **6 位**（32⁶ ≈ 10 亿），配合频率限制，枚举基本不可行。
- 限速：建房 10 次/小时、查房 20 次/分钟、加入 30 次/分钟、开新局 30 次/分钟。
- 没有做全局口令：目标是“把地址和 6 位码发朋友就能玩”，加口令会把这步变复杂。代价是**知道房间码的人就能进**，所以别公开贴地址。

### 7. 已知的坑（写代码时踩过）

- **`#room-screen` 必须显式设 `flex-direction: column`**：`.screen.active { display: flex }` 默认是 row，会导致大厅布局塌成一条横条（已修，见 `style.css`）。
- **测试脚本的 CDP 端口**：并发跑多个浏览器脚本时，旧的无头实例会占着固定端口，`/json/list` 会连到**上一轮的页面**，导致截图内容和断言对象都是旧的。`room-ui.mjs` 现在用随机端口 + `pickFreePort` + `Browser.close` 优雅退出。
- **`dotnet build` 前必须先停服务**，否则 DLL 被锁（`MSB3027`）。
