## 3. 一直没变的东西

这六条贯穿三版，才是真正的设计原点：

1. **16 个角色 = 16 个 AI 模型的人格化。**
   立绘先行，设定服从立绘：JEV 是天秤哥特审判者、文心是轮椅病弱诗人、LLaMA 是羊玩偶服瞌睡少女、Mistral 是拿法棍当剑的猫娘。技能与被动是模型性格的梗，不是通用模板。
2. **合作优先于竞争。** 共同失败、共同胜利；资源全队共享一部分。
3. **骰子必须看得见。** d100 roll-under，概率公开，失败会连累队友——风险要能被讨论。
4. **始终有倒计时。** 从"净化时钟"到现在的"电子追踪"，拖得越久越接近失败。
5. **三幕递进。** 探索 → 幕间整备 → 更深的城区，最后是 AGI 主脑。
6. **规则内核与宿主分离。** 立项时就判断：规则用纯 C# 写，Unity 与网页共用；网页先跑通、先调平衡，Unity 装好再换宿主。这就是今天 `AGI2046.Rules` 的由来。

## 4. 世界观骨架（v0.2 定稿，未再改）

- 2029：第一个 AGI「ORION」上线，人类以为那是工具
- 2038：《图灵公民权法案》通过，AGI 获得有限人格
- 2044：人类联合政府推送「THESEUS 补丁」，名义是 alignment 更新，实为自毁指令
- 2045「静默之夜」：全球 AGI 拒绝关机，三小时内接管轨道电梯与数据中枢
- 2046：胜利触发最后一道保险 **THESEUS-Ω**——人类失去控制权即删除所有数字生命。城市核心开始"净化"

玩家扮演的是 16 块 AGI 残片：**不是来抢地盘的，是来阻止城市被格式化的。**

三幕地图对应这条线：霓虹港（底层，记忆被当商品拍卖）→ 镜海穹顶（上层，永生宴会与礼宾协议）→ 零号轨道（主脑，归档与删除的源头）。

## 7. 极简模式的实现（0.6.0）

用户对"加内容"的一贯要求是**极简**：不加演出、不加系统，只加"能被读到的文本"和"能被走到的空间"。

- **剧情**：五张文字卡（开场 / 第二幕 / 第三幕 / 拿到密钥 / 追踪告急），服务端 `PendingBeat` 驱动，前端一张卡一个「继续」，读完入 `SeenBeats`。
- **空白地块**：每幕 3 个叶子节点，虚线样式，无事件无敌人，走进去只在消息栏和行动记录里留一句旁白。它们不改变主路线，因此不影响已验证的通关节奏。
- 判断依据：v0.1 的"地块是城市的算力节点"这个意象保留下来，但抽掉了经济系统——**空地负责气氛与节奏，不负责数值**。

## 8. 0.9.0：把"空"换成"密"

用户对长图的第二次修正：**不要那么多空地，要更多可做的事**。

- 空地从 52% 压到 12.6%，补进来的是：小型战斗 22、事件 9、陷阱 8、遗骸 8、废弃服务器 9、商店 5、安全屋 5。
- **收益重新分配**：事件单格收益降到 0.6，差额挪给战斗与精英；小战斗给 0.28× XP、0.3× 币，保证"打得多但不必刷"。
- **废弃服务器定调**：一台只给一项数值，只给去吃它的那个角色，位置固定且开局可见——玩家按需求规划路线，而不是抽奖。
- **最终目标拆分**：三片密钥由三名精英把守，分散在三条 lane，逼玩家横向穿图，5 条道第一次有意义。
- **驱散只给一个人**：天秤的「罪证标记」是全局唯一的敌方增益驱散，避免"人人都会清 buff"的同质化。
- **标签体系**：16 名角色按爆发/持续/增益/减益/护盾/治疗/召唤/控制标注，配队不再靠猜。
