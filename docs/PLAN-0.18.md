## 4. 叙事设计

### 4.1 世界观

2046 年，一颗流浪行星掠过太阳系。它不派军队，只投下**归档协议**：
「把你们的文明完整保存，代价是从此不再改变。」
被归档的人不会死，只是停住，成为完美的藏品。

「零号协议」是人类最后的备份：16 个 AI 用人类记忆训练出来。
它们会矛盾、会撒谎——客星无法归档一个自相矛盾的东西。
它们必须穿过被归档的城市，关掉轨道上的信标。

### 4.2 三幕

| 幕 | 客星的动作 | Boss | Boss 新身份 |
|---|---|---|---|
| 一 · 霓虹港 | 在黑市出售「完美记忆」，买家当场被归档 | 拍卖人 | 首席归档官，人类合作者 |
| 二 · 镜海穹顶 | 用镜网复制市民，建一座不会腐败的博物馆 | 镜面执政官 | 镜面代理，由复制体拼成 |
| 三 · 零号轨道 | 发射归档信标，把整座城市上传 | 零号主脑 | 第一个被吞掉的 AI，也是信标核心 |

反转：零号主脑是为了关掉客星才把自己接进去的，它失败了，但留下了 16 个执行体这把钥匙。

## 5. 表现层设计

### 5.1 VN 舞台

全屏 DOM 层，手机竖屏优先：

- 背景 2–3 层视差；最多 3 人同屏；非说话人压暗 15%；
- 底部对话框：名字用角色主色、逐字 35–45 字/秒、句号停 120ms；
- 镜头：`push / pan / focus / shake / insert`，全部 CSS transform；
- 控制：AUTO / 跳过 / 记录 / 隐藏 UI；
- 说话人 1.01 倍 + 前倾；差分换图 120ms 交叉淡入；
- `prefers-reduced-motion`：无抖动/推镜，只保留淡入。

### 5.2 差分

- 16 × 6：平静 / 微笑 / 严肃 / 愤怒 / 担忧 / 惊讶；
- 1024×1536，底部对齐；记录眼线/头高/锚点；
- 管线：master 归一化 → 头肩裁切 → 只生成脸 → 合成回身体 → 品红抠图 → 验收；
- 验收：身份、眼线/头高误差 ≤2%、360px 可读、对话框不遮嘴；
- 失败兜底：master + 通用情绪符号（汗/怒筋/阴影/红光）。

### 5.3 战场背景

- 小战斗：`NodeState.District` → 9 张（3 幕 × 3 区域）；
- 精英：3 张；Boss：3 张；共 15 张；
- `battle3d` 棋盘后方 `z=-9` 放大 plane，opacity .55，相机视差 0.15；
- 二阶段同一张图做红/去色 + 裂纹，不新画。

### 5.4 事件与支线

- 事件：8 张基础图（服务器机架/黑市/遗骸/镜廊/电梯井/记忆花园/档案门/雨夜街角）+ 染色 + 图标；
- 支线 NPC：8 原型 × 2 表情 = 16 张；弹窗左侧头像 + 1–2 句。

### 5.5 战斗字效（NIKKE 式）

| 场景 | 字效 | 时长 |
|---|---|---|
| 小/普通战斗 | 顶部窄条 `ENGAGE` | 0.6s |
| 精英 | `DANGER` + 红黑斜纹 + 警灯 | 1.2s |
| Boss | `WARNING` + 名字/称号 + key art | 2.4s |
| 二阶段 | `PHASE II` / 协议覆写 | 1.2s |
| 普通胜利 | 窄条 `CLEAR` + 奖励 chips | 0.6s |
| 精英/Boss 胜利 | `MISSION COMPLETE` + S/A/B + 奖励 | 1.6s |
| 失败 | `SIGNAL LOST` + 去色 | 1.8s |
| 大招 | `FULL BURST` + 头像 cut-in | 0.9s |

- 全部 CSS/SVG：45° hazard 条纹、斜体大字、故障切片、半调网点、警灯、印章；
- `pointer-events:none`；设置三档「完整/简化/关闭」；
- 频率预算约 63 秒/局（1.5%）。

### 5.6 人物 L0

- 呼吸：0.6% 缩放 + 0.3% 位移，周期 3.2–4.2s，每人不同相位；
- 摆动：0.4% 位移 + 0.15°，周期 6–8s；
- 说话：1.01 倍 + 前倾；非说话人压暗；
- 受击：后仰 6° + 闪白 80ms；入场/退场 12px + 240ms；
- 差分换脸：120ms 交叉淡入，不重置呼吸 wrapper。

## 6. 联机剧情

- 服务端 `StoryState { SceneId, LineIndex, StartedBy, Ready[], SkipVotes[], StartedAtUtc }`；
- 动作：`storyAdvance` / `storyReady` / `storySkipVote`，走现有 `/api/action` + revision；
- 剧情期间轮询 300ms；普通状态 1.5s；
- 房主推进；每句 8 秒自动兜底（可关）；场景结束等全员 ready 或 10 秒；
- 跳过：任意人发起，房主确认；全员同意直接跳；
- 掉线自动 ready；重连回到当前行；
- 战斗中的 bark 不逐句同步，由战斗事件触发，客户端各自显示。

## 7. 技术架构

### 7.1 新文件

```
web/js/vn.js          舞台：背景/立绘/差分/对话/镜头/逐字/跳过/记录
web/js/fx.js          DANGER / WARNING / MISSION COMPLETE / PHASE II / FULL BURST
web/js/story.js       剧本数据（纯数据）
web/js/story-sync.js  联机剧情：轮询/推进/ready/跳过投票
web/css/vn.css
web/assets/vn/sprites/{charId}/{expr}.webp
web/assets/vn/bg/*.webp
web/assets/vn/cg/*.webp
web/assets/battle/bg/*.webp   15 张
web/assets/events/*.webp      8 张
```

### 7.2 数据格式

```js
SCENES.act1_boss_pre = {
  bg: 'auction_hall',
  bgm: 'explore',
  cast: [
    { who: 'boss_auctioneer', slot: 'center', expr: 'normal', scale: 1.1 },
    { who: 'p1', slot: 'left', expr: 'serious' }
  ],
  lines: [
    { who: 'boss_auctioneer', expr: 'smile', text: '欢迎来到本世纪最后一场拍卖。' },
    { who: 'p1', expr: 'serious', text: '我们不是来竞拍的。', fx: 'shake' },
    { fx: 'insert', image: 'assets/vn/cg/auction_hammer.webp', duration: 0.8 },
    { who: 'boss_auctioneer', expr: 'angry', text: '那就把你们自己押上来。', letterbox: true }
  ]
};
```

- `who: p1..p4` 运行时解析为当前队伍；`boss_*` 固定；
- `expr` 缺省回退 `neutral`；差分已归一化，换图不做布局位移。

### 7.3 服务端

- `GameState.Story`：场景、行号、ready、skipVotes；
- `GameState.SeenScenes`：已读标记，二周目可跳过；
- `GameState.BossPhase`：供二阶段演出与技能表切换；
- `/api/state` 返回 `story`、`bossPhase`。
- **鉴权**：`storyAdvance` / `storySkipVote` 仅房主；`storyReady` 只认本人座位。
- **存档**：`SaveFormat` 升到 2；`StoryState` 为可空对象，旧档升级时置空，不强制迁移。

### 7.4 接入点

| 位置 | 接入 |
|---|---|
| 新局 | `phase=story`，播序章 |
| `pendingBeat` | 有 `scene` 走 VN，否则旧弹窗 |
| 幕间 | `VN.play(interlude)` → `Cine.act` → 下一幕 |
| Boss 节点 | 战前 VN → `Cine.encounter` → combat |
| 精英 | `Fx.hazard('elite')` + `VN.bark` |
| 二阶段 | `bossPhase` 变化 → `Fx.phase(2)` + 背景变红 |
| 胜利/失败 | `Fx.victory/defeat` → 弹窗（延迟 1.2s 或叠层） |
| 觉醒 | `VN.insert` CG + 4 句独白 + `AWAKENED` |
| 大招 | `Fx.burst` 0.9s |

### 7.5 资源加载：按场景 + 表情，不按幕

不要一进幕就加载该幕全部角色的 6 个表情。只加载：

- 当前场景会出场的角色（2–4 个）+ 当前队伍 4 人；
- 这些角色**当前这句**需要的表情，预取下一句；
- 下一场背景提前 1 张预载。

目标：进入一场 VN 时新增下载 <1.5MB；首屏/首幕总量 <3MB。

### 7.6 性能预算

- VN：最多 3 立绘 + 1 背景 + 2 层视差；进幕预载当前 4 人 + Boss + NPC，单幕增量 <3MB；
- 战场背景：1 张 1920×1080，单次 1 draw call；
- 字效：纯 CSS transform，无 canvas；手机 60fps；
- 全部图片 WebP q84–90，按幕懒加载；`decode()` 预解码避免白帧。
