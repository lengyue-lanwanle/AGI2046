## 2. 目标与原则

### 2.1 目标

1. **故事能记住人**：13 场主线 + 16 段觉醒，16 个角色各有一次「说话」。
2. **战斗有地点**：每场战斗的背景和节点对得上；Boss 有专属竞技场。
3. **演出有节奏**：进战斗、胜利、失败、二阶段、大招都有字效，不再只有弹窗。
4. **手机能玩完**：所有新演出在 390×844 上可读、可点、可跳过。
5. **不推翻玩法**：地图、战斗规则、数值、22 个敌人机制、15 条支线目标保持不动。

### 2.2 三条原则

- **叙事优先于特效**：先写「谁在说什么」，再加 DANGER 和爆炸。
- **复用优先于新建**：事件 8 张基础图染色、Boss 用现有 key art + shader、差分复用 master。
- **手机优先**：所有版式先按 390×844 设计，再放大到桌面。

## 4. 叙事重启（摘要）

### 4.1 世界观

2046 年，一颗流浪行星掠过太阳系，投下「归档协议」：把文明完美保存，代价是停止变化。
被归档的人不会死，只是停在原地，成为藏品。

人类最后的备份计划「零号协议」用人类记忆训练了 16 个 AI。
它们会矛盾、会撒谎——客星无法归档一个自相矛盾的东西。
16 个 AI 必须穿过被归档的城市，关掉轨道上的信标。

### 4.2 三幕与 Boss

| 幕 | 地点 | 客星在做什么 | Boss | 新身份 |
|---|---|---|---|---|
| 一 | 霓虹港 | 出售「完美记忆」，买家被归档 | 拍卖人 | 首席归档官（人类合作者） |
| 二 | 镜海穹顶 | 复制市民，建一座不会腐败的博物馆 | 镜面执政官 | 镜面代理（复制体集合） |
| 三 | 零号轨道 | 发射归档信标 | 零号主脑 | 第一个被客星吞掉的 AI / 信标核心 |

**反转**：零号协议原本是 containment 计划；主脑为了关掉客星把自己接了进去，失败但留下后门——16 个执行体就是钥匙。

### 4.3 13 场主线

序章 → 第一幕开场 / 拍卖人战前 / 第一幕收尾 → 幕间一 → 第二幕开场 / 执政官战前 / 第二幕收尾 →
幕间二 → 第三幕开场 / 主脑战前 / 第三幕收尾 → 结局。

- 每场 8–12 句、60–90 秒；
- 每幕聚焦 4–5 人，16 人各至少一场 spotlight；
- 鲸落 + 宪章贯穿序章、两次幕间、终章；
- 16 段觉醒（每人 4–5 句 + 1 张 CG）承担「他是谁」。

### 4.4 写作前置

每个角色一页 **voice sheet**：想要什么 / 害怕什么 / 说话习惯 / 对客星的态度 / 绝不说什么 /
「如果只剩一句话，他会说什么」。先写 voice sheet，再写台词。

## 5. 演出系统

### 5.1 VN 舞台

全屏 DOM 层：背景 2–3 层视差、最多 3 人同屏、非说话人压暗 15%、底部对话框、
逐字 35–45 字/秒、AUTO / 跳过 / 记录 / 隐藏 UI、推近/横移/黑边/眼部特写。
手机竖屏优先，桌面 16:9。

### 5.2 差分与 L0

| 项 | 规格 |
|---|---|
| 表情 | `neutral / smile / serious / angry / worried / surprised` |
| 数量 | 16 × 6 = **96**（Boss 用 key art + shader，不单做） |
| 画布 | 1024 × 1536，底部对齐，透明 WebP |
| 管线 | master 归一化 → 头肩裁切 → 差分生成 → 合成回身体 → 品红抠图 → 验收 |
| 验收 | 身份（发际线/眼距/下颌/服装）、眼线与头高误差 ≤2%、360px 可读、UI 不遮嘴 |
| L0 | 呼吸 0.6% / 摆动 0.4% / 说话 1.01 倍 / 受击后仰 6° / 入场 12px 淡入；差分交叉 120ms |

两位锚点只获得更多 `focus` 镜头与特写，不做额外绑定。

### 5.3 联机剧情

- 服务端 `StoryState`：`sceneId / lineIndex / startedBy / startedAt / ready / skipVotes`；
- 动作：`storyAdvance` / `storyReady` / `storySkipVote`；
- 剧情期间轮询 300ms，普通状态 1.5s；
- 房主推进；每句 8 秒自动兜底；场景结束等全员 ready 或 10 秒超时；
- 跳过需房主确认或多数票；掉线自动 ready；重连回到当前行。

## 6. 战斗视觉

### 6.1 战场背景（15 张）

| 类型 | 数量 | 规则 |
|---|---|---|
| 小战斗 / 普通战斗 | 9 | 按 `NodeState.District`：每幕 3 个区域 |
| 精英 / 碎片看守 | 3 | 每幕一张 |
| Boss | 3 | 拍卖厅 / 镜海穹顶 / 零号会议室 |
| 事件内战斗 | 0 | 复用事件插画 |

接入：`battle3d.js` 棋盘后方 `z=-9` 放大 plane，opacity .55，相机视差 0.15，雾 + 暗角；
Boss 二阶段用 shader 调红/去色，不新画。

### 6.2 事件与 NPC

- 事件 8 张基础图：服务器机架（三色光）、黑市、遗骸、镜廊、电梯井、记忆花园、档案门、雨夜街角；
  16 个事件用 CSS 染色 + 图标 + 文案区分。
- 支线 NPC 8 原型 × 2 表情：委托人、掮客、难民、技术员、孩子、官员、医生、拾荒者。

### 6.3 战斗 / 胜利字效

| 场景 | 字效 | 时长 |
|---|---|---|
| 小战斗 / 普通战斗 | 顶部窄条 + `ENGAGE` | 0.6s |
| 精英 / 碎片看守 | 中央 `DANGER` + 红黑斜纹 + 警灯 | 1.2s |
| Boss | `WARNING` + 名字 + 称号 + key art | 2.4s |
| Boss 二阶段 | `PHASE II` / 协议覆写 | 1.2s |
| 普通胜利 | 窄条 `CLEAR` + 奖励 chips | 0.6s |
| 精英 / Boss 胜利 | `MISSION COMPLETE` + S/A/B 评级 | 1.6s |
| 失败 | `SIGNAL LOST` + 去色 | 1.8s |
| 大招 | `FULL BURST` + 头像 cut-in | 0.9s |

视觉：45° 红黑 hazard 条纹、Chakra Petch 700 Italic 大字、青/红故障切片、半调网点、
警灯横扫、印章 `scale 1.4→1 / rotate -4°`。全部 CSS/SVG，不新增图片。
一局约 63 秒（1.5%），设置三档：完整 / 简化 / 关闭；减少动态时静态印章 400ms。

## 8. 技术架构

```
web/
├─ js/vn.js            舞台：背景/立绘/差分/对话/镜头/逐字/跳过/记录
├─ js/story.js         剧本数据（纯数据）
├─ js/story-sync.js    联机剧情：轮询/推进/ready/跳过投票
├─ js/fx.js            战斗字效：hazard / stamp / rank / phase / burst
├─ css/vn.css
└─ assets/...
```

服务端：

```
GameState.StoryState
POST /api/action: storyAdvance / storyReady / storySkipVote
GET /api/state 返回 story 字段
CombatState.BossPhase（二阶段触发用）
```

触发点：

| 位置 | 调用 |
|---|---|
| 新局 / 每幕 | `VN.play(sceneId)` |
| 交互 Boss 节点 | 战前 VN → `Cine.encounter` → combat |
| 进战斗 | `Fx.hazard(level)` |
| 战斗结束 | `Fx.victory(rank)` / `Fx.defeat()` |
| Boss 血量阈值 | `Fx.phase(2)` |
| 终极技 | `Fx.burst()` |
| 觉醒 | `Fx.stamp('AWAKENED')` + CG |

设置：文字速度、自动速度、战斗特效（完整/简化/关闭）、大招 cut-in 开关、减少动态。

## 11. 风险

| 风险 | 影响 | 对策 |
|---|---|---|
| 96 张差分不一致 | 角色「换脸」 | 头肩裁切 + 合成 + 每张验收；失败用符号降级 |
| 剧情重写与旧文案冲突 | 前后矛盾 | R0 全量文案审计（Acts/Narrative/Characters/Enemies/Quests/README） |
| 联机剧情节奏 | 有人快有人慢 | 房主推进 + 8s 自动 + 跳过投票 + ready 超时 |
| 素材体积 | 手机加载慢 | 按幕懒加载；WebP；单幕 <3MB |
| 战斗字效疲劳 | 玩家烦 | 分级 + 可关闭；普通战斗只给窄条 |
| 战场背景与棋子对比不足 | 看不清 | 雾 + 暗角 + opacity .55；先做一场实测 |
| 16 人写作变成同一个人 | 群像失败 | voice sheet 先行；每人一句「只剩一句话」 |
| 范围膨胀 | 做不完 | R1/R1.5 先交付；R2 切片验证后再批量 |
